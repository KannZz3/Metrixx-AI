[![Language](https://img.shields.io/badge/Language-English%20%2F%20Chinese-blue.svg)](#)

Metrixx-AI is the public, isolated research subset of the METRIXX / MY DESK market-intelligence stack. This repository focuses on one practical layer: turning permitted commodity, macro, positioning, and narrative inputs into normalized, validated, compliance-labeled records that can feed Basis Sentiment, COT scoring, prompt workflows, WATOS-style alerts, and VAULT-ready outputs.

中文简述：本仓库不是完整生产平台，而是一个面向商品市场情报的轻量数据智能子集。核心任务是抓取合规数据源，标准化字段，生成验证报告，再把结果用于基差情绪、COT 持仓、新闻叙事和 AI prompt 输出。

## Scope

Included:

- Lightweight Python ingestion and normalization scripts.
- Checked-in sample outputs in JSON / CSV.
- Validation reports for the current public subset.
- A minimal source-compliance gatekeeper catalog.
- A reproducibility snapshot script for auditing checked-in results.

Excluded:

- Production subscriber backend.
- Proprietary databases and private platform services.
- Full MY DESK / VAULT production deployment.
- Licensed raw data redistribution.

## Gatekeeper Model

All normalized records are expected to carry source status fields such as `tos_status`, `gatekeeper_cleared`, `gatekeeper_id`, and `raw_source_url`.

The minimal source policy now lives in [catalog.json](catalog.json):

- `GO`: EIA, USDA AMS, CFTC, FRED, Baker Hughes.
- `GO_INTERNAL_ANALYTICS`: CME reference / settlement fields and Massive CME futures sessions used for internal analytics samples.
- `REVIEW_PARAPHRASE_ONLY`: Reuters and similar sources, headline/snippet only.
- `HOLD`: sources pending licensing or AI/data-use approval.
- `RED`: hard-blocked sources.

## Data Contracts

The shared normalized-record contract is intentionally simple:

```text

timestamp
data_type
value
unit
tos_status
gatekeeper_cleared

```

Domain-specific pipelines add fields for basis, futures contracts, COT positioning, narrative events, source mapping status, proxy notes, and validation metadata.

## Running Individual Components

Most scripts are standalone. External fetchers require source-specific credentials or local files:

```bash
# EIA
set EIA_API_KEY=your_key_here
python Data_light_version/EIA/eia_physical_price_fetcher.py --length 30
python Data_light_version/EIA/normalize_eia.py

# USDA
set USDA_MARS_API_KEY=your_key_here
python Data_light_version/USDA/usda_unified_fetcher_light_v4_commodity_split_fixed.py --days 60 --limit-per-target 30

# CFTC
python Data_light_version/CFTC/cftc_cot_fetcher_light_v5_field_quality_fixed.py --limit-per-symbol 156 --query-limit 5000
python COT_scoring_positioning/cftc_cot_scoring_v1.2.py

# CME via Massive Futures REST
set MASSIVE_API_KEY=your_key_here
python Data_light_version/CME/massive_cme_futures_fetcher.py --as-of-date 2026-06-15 --history-days 7 --contracts-per-product 3

# Narrative
python Data_light_version/Reuters/_reuters_eia_narrative_light_v1_6.py
python Data_light_version/Reuters/narrative_ng_zc_zs.py

# Baker Hughes
python "Data_light_version/Baker Hughes/baker_hughes_rig_count_light_2026.py" --local-file "Data_light_version/Baker Hughes/05-22-2026 North_America Rig_Count Report.xlsx"

# Basis Sentiment fusion from checked-in/local outputs
python Basis_sentiment/build_basis_sentiment_from_cme.py
```

PowerShell users can set environment variables with `$env:EIA_API_KEY="..."`, `$env:USDA_MARS_API_KEY="..."`, and `$env:MASSIVE_API_KEY="..."`.

## Architecture Note

The backend guidance in `Data_backend/adding-polygon-provider.md` defines the intended provider-adapter pattern:

- Provider-specific logic belongs inside provider adapters.
- Services consume normalized contracts.
- New provider breadth should be exposed through capability interfaces, not provider-name branching.

This architecture note is included as reference for the broader platform, but the full provider relay implementation is outside this public subset.

## Known Boundaries

- No production database schema is included.
- No CI pipeline is included.
- FRED outputs are included, but a FRED fetcher script is not included in this snapshot.
- CME data is licensed/internal analytics only in this public subset; do not commit API keys or redistribute raw licensed data beyond permitted outputs.
- `Docs/` contains product and sprint material but is not required to run the lightweight code.
